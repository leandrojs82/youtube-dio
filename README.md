# YouTube — Desafio de Flexbox da DIO

Reprodução do frame “Youtube - Assistindo Vídeo” usando apenas HTML5 e CSS3, com Flexbox e adaptação para celular. Sem JavaScript, bibliotecas, instalação ou etapa de compilação.

## Como abrir

Extraia o ZIP e abra `index.html` no navegador. Mantenha `styles.css` e a pasta `assets` ao lado do HTML. As imagens e fontes são locais; a página pode ser visualizada sem internet.

## Arquivos

- `index.html`: estrutura semântica, cabeçalho, vídeo e recomendações.
- `styles.css`: fonte, cores, Flexbox e media queries em 1280, 1000 e 600 px.
- `assets/`: imagens, ícones e fontes Roboto.

## Escopo

Esta é uma reprodução visual estática do Figma. O vídeo é uma imagem; os controles de inscrição, curtida, notificações, compartilhamento e download são demonstrativos. A pesquisa e os links externos abrem o YouTube e exigem internet. A versão para celular é uma adaptação do frame desktop.
